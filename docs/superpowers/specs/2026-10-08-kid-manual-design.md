# AI 탐험대 어린이용 설명서 설계 (2026-10-08)

대상: 초4~중1 학생과 선생님. 목표: 설명서만 보고 혼자 설치하고 끝낼 수 있게 한다. 이 문서는 설계서이며 설명서 본문이 아니다.

## 1. 산출물과 위치

| 파일 | 설명 |
|---|---|
| `package/설명서.html` | 한 파일 자체 완결형. 화면용 + A4 인쇄용. CSS는 인라인, 이미지는 상대경로 |
| `package/설명서.pdf` | 위 HTML을 Edge로 인쇄한 PDF (A4 세로, 배경색 포함) |
| `package/manual_img/*.png` | 스크린샷, 로고, 마루. 파일명은 `s01_download.png`처럼 `s{번호2자리}_{영문키}.png` |
| `package/사용법.txt` | 그대로 둔다 (메모장용 짧은 안내). 설명서 첫 줄에 "그림 설명서가 있어요"를 추가 |

- zip 안에서는 `설명서.html`, `설명서.pdf`, `manual_img/`가 `AI탐험대.exe`와 같은 폴더에 놓인다.
- 이미지는 PNG, 가로 1280px 이하, 파일당 300KB 이하로 줄인다 (`Pillow` quantize).
- 마스코트와 로고는 `assets/maru_hero.png`, `assets/maru_cheer.png`, `assets/brand/logo_512.png`를 `manual_img/`로 복사해 쓴다. 원본은 건드리지 않는다.

한 쪽에 한 단계. 단계마다 큰 그림 1장, 문장 최대 2개, 필요할 때만 "꼭 기억해요" 상자.

## 3. 시각 디자인

`DESIGN_SYSTEM.md` 토큰을 `:root` 변수로 그대로 쓴다.
- 색: 종이 `#FBF7EC`, 글씨 `#141414`, 코발트 `#3D5AFE`, 노랑 `#FFB800`, 초록 `#12B76A`. 경고/클릭 표시는 빨강 `#E5322D` 하나만 추가한다.
- 모양: 3px 잉크 테두리, 오프셋 그림자(`6px 6px 0 #141414`), 둥근 카드(`radius 20px`).
- 글자: 본문 18px 이상(최소 16px), 제목 32px, 단계 번호 56px. 폰트는 `Pretendard`/`Noto Sans KR`/`Malgun Gothic` 순. 외부 CDN은 쓰지 않는다 (오프라인 사용).
- 단계 배지: 코발트 원 안에 흰 숫자(① ~ ⑪), 쪽 왼쪽 위.
- 마루 말풍선: 오른쪽 아래 마루 이미지(`maru_cheer.png`, 높이 120px) + 노란 말풍선에 짧은 응원 한 줄 ("잘했어요!").
- "꼭 기억해요" 상자: 노란 바탕, 전구 아이콘, 3px 테두리. 쪽당 최대 1개.
- 스크린샷 강조: 그림 위에 `position:absolute` 빨간 원(3px 테두리, 반투명 채움)과 화살표 SVG. 좌표는 이미지 크기에 대한 `%`로 저장한다 (§4 `callouts.json`).
- 아이콘: 인라인 SVG만 사용 (이모지는 PDF 폰트 차이가 있어 쓰지 않는다).
- 인쇄: `@page { size: A4; margin: 12mm }`, `print-color-adjust: exact`, `break-after: page`로 단계마다 쪽 나눔, 그림 `max-height: 150mm`, 그림자는 인쇄 시 유지하되 흑백에서도 구분되도록 번호 배지에 숫자를 반드시 넣고 강조는 색이 아닌 굵은 선과 화살표로 한다.
- 화면: 본문 폭 `max-width: 900px` 가운데 정렬, 1366px 화면 100%에서 한 단계가 한 화면에 가깝게 들어온다. 맨 위에 쪽 건너뛰기 목차.

## 4. 스크린샷 계획

모든 그림은 사람 손 없이 백그라운드에서 만든다. 공통: Playwright Python, `channel='msedge'`, `headless=True`, 기기 배율 2 (`device_scale_factor=2`) 후 1280px 이하로 축소.

### 4.1 앱 화면 (진짜 캡처)
- 서버: `dist\AI탐험대\AI탐험대.exe --no-browser --port 47816` 을 하위 프로세스로 띄우고 `http://127.0.0.1:47816/ping` 응답을 기다린 뒤 캡처한다. 끝나면 프로세스를 종료한다. 운영 포트 47815와 겹치지 않게 테스트 포트를 쓴다.
- 브라우저 실행 인자: `--use-fake-ui-for-media-stream --use-fake-device-for-media-stream`.
- 뷰포트: 1280x800 (앱 창 느낌). 허브 첫 화면은 1280x720.

| id | 보여주는 것 | 만드는 방법 | 강조 |

| s05_hub | 허브 첫 화면 | `/` 로 이동, 폰트 로드 대기 후 전체 캡처 | 제목에 빨간 원 |
| s06_pick | 중급 14~25강 카드 목록 | `/` 에서 카드 영역만 `locator.screenshot()` | 한 카드에 빨간 원 + 손가락 화살표 |

### 4.3 강조 표시(callout) 방식
- `tools/manual/callouts.json`에 `{ "s04a_smart": [{"type":"circle","x":0.62,"y":0.71,"r":0.06},{"type":"arrow","from":[0.8,0.5],"to":[0.65,0.69]}] }` 형식으로 이미지 크기 대비 비율 좌표를 둔다.
- 앱 화면은 locator의 `bounding_box()`를 읽어 비율로 자동 계산한다. 모형은 HTML 안에 `data-callout` 속성을 둔 요소의 상자를 읽어 자동 계산한다. 손으로 좌표를 적는 일을 최소화한다.
- 합성은 HTML 단계(SVG 겹침)에서 하므로 이미지 파일에는 표시가 이미 구워져 있다.

### 4.4 생성 스크립트
```
tools/manual/
  capture.py        # 서버 기동 → 앱 캡처 → mock/*.html 캡처 → manual_img/ 저장
  mock/*.html       # Windows 모형 + mock/common.css
  callouts.json
  manual.template.html   # 본문 틀 (문구는 여기 한 곳)
  build_manual.py   # 틀+이미지 → package/설명서.html, Edge --headless --print-to-pdf → 설명서.pdf
  build_all.ps1     # 한 명령: capture → build_manual → 검사
```
- 한 번에: `powershell tools\manual\build_all.ps1`. 실행 전 `pip install playwright pillow` 안내와 exe가 없으면 `build.ps1`을 먼저 돌리라는 오류 문구를 낸다.
- PDF: `msedge --headless --disable-gpu --no-pdf-header-footer --print-to-pdf=package\설명서.pdf file:///.../설명서.html`.
- `build.ps1` 연동: 26행의 `사용법.txt` 복사 줄 아래에 `설명서.html`, `설명서.pdf`, `manual_img\` 복사를 추가한다. 설명서 파일이 없으면 경고만 내고 빌드는 계속한다 (설명서가 배포를 막지 않게).

## 5. 말투 규칙

- 한 문장 한 동작. 문장은 20자 안팎, 최대 2문장. "~해요" 체.
- 쓰는 말: "누르기", "두 번 누르기", "오른쪽 버튼으로 누르기", "창", "파일", "폴더", "나침반 그림".
- 안 쓰는 말: 실행 파일, 서버, 포트, 로컬, 인증서, 다운로드(→ "받기", 단 Edge 화면 글자는 그대로). 버튼 이름은 항상 [대괄호]로 쓰고 그림 속 글자와 똑같이 쓴다.
- 놀람을 줄이는 문장을 넣는다: "파란 창이 나와도 놀라지 마세요", "고장이 아니에요".
- 마루 말풍선은 "잘했어요!", "다음으로 가요" 같은 칭찬과 격려만 쓴다.

### 선생님용 상자 (마지막 쪽, 5줄 이내)
- exe는 서명되지 않아 SmartScreen이 뜹니다. 학교 보안 정책으로 막히면 온라인 주소를 쓰세요.
- 앱은 내 컴퓨터(127.0.0.1:47815)에서 작은 웹 서버로 돌고 Edge 앱 창으로 열립니다. 학생 정보는 밖으로 나가지 않습니다.
- 진행 기록은 이 컴퓨터의 브라우저 저장소에만 있습니다. 15강 음성 인식은 인터넷이 필요합니다.
- 포트 충돌 메시지가 반복되면 재부팅하거나 온라인 주소를 쓰세요.
- 닉네임이나 번호를 쓰게 지도해 주세요.

## 6. 검수 기준

1. `manual_img/`의 모든 이미지가 존재하고, HTML의 모든 `src`와 링크가 실제 파일을 가리킨다 (build_manual.py가 검사하고 실패하면 종료 코드 1).
2. 모든 단계 쪽에 이미지가 정확히 1개 있고, 설명 문장은 2개 이하다 (HTML 파싱 검사).
3. 본문 글자 크기가 16px 이상이다 (계산된 스타일 검사).
4. PDF는 10쪽 안팎(12쪽 이하), A4, 폰트 포함, 3MB 이하.
5. 1366px 폭 화면 100%에서 가로 스크롤이 없고 단계 하나가 한 화면 높이 안팎이다 (1366x768 캡처로 확인).
6. 컬러와 흑백(그레이스케일 변환 PDF) 모두에서 번호 배지, 빨간 표시(굵은 선과 화살표)를 알아볼 수 있다.
7. MessageBox 모형 글자가 `Program.cs`와 일치하고, 금지어(실행 파일, 서버, 포트 등)가 선생님 상자와 그림 속 글자 밖에는 없다.
8. 한 명령 `build_all.ps1`로 전부 다시 만들어지고, 두 번 돌려도 결과가 같다.
9. zip을 풀었을 때 `설명서.html`이 `AI탐험대.exe` 옆에서 열리고 그림이 모두 보인다.

범위 밖: 실제 Windows 화면 직접 촬영, 영상 안내, 영어판.
